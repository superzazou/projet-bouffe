**As a** meal planner, **I want to** see dates in my planning week grid that match my local calendar, **so that** I can plan meals for the correct days without timezone-induced day shifts.

<objective>
Fix the UTC timezone bug in PlanningWeek.tsx (FND-01): getMondayOf parses bare ISO date strings as UTC midnight, causing the wrong weekday in UTC-negative timezones; toDateStr emits a UTC date string that shows the previous day for users west of UTC. This tracer task rewrites both utilities with local-date operations and introduces a client-derived todayStr replacing all uses of the server-passed today prop in display and comparison logic.

Purpose: Eliminate the root cause of wrong-day display before the layout refactor, making the timezone fix independently reviewable and rollback-safe.
Output: PlanningWeek.tsx with timezone-safe getMondayOf, toDateStr, and a todayStr local constant — component builds and lints cleanly.
</objective>
