| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-06 | Tampering | recipe title rendered inside RecipeCombobox in bottom sheet | low | accept | React escapes all JSX text; RecipeCombobox does not use dangerouslySetInnerHTML; recipe titles are display-only |

| T-02-08 | Spoofing | bottomSheet.date sourced from selectedDay state | low | accept | Date string derived from local navigation state (same source as all other date operations); not free-text user input; tampered date would only affect the caller's own planning view |
