## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Tailwind class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | gap-1, p-1 | Pill label vertical micro-gap |
| sm | 8px | gap-2, p-2 | Slot inner padding, recipe row icon gap |
| md | 16px | gap-4, px-4 | Pill horizontal padding, button horizontal padding |
| lg | 24px | gap-6, p-6 | Day content section padding, bottom sheet padding |
| xl | 32px | gap-8 | Slot-to-slot vertical gap within day view |
| 2xl | 48px | — | Reserved for page-level vertical rhythm |
| 3xl | 64px | — | Reserved for major layout breaks |

**Exceptions:**
- Mini-bar pills: minimum touch target height 44px (`min-h-[44px]`). Internal visual padding may be sm/md but the interactive area is always 44px tall.
- "+" add button per slot: minimum touch target 44×44px. Implement as `w-11 h-11` (44px) rounded-full button or wrap in a 44px tall container.
- "Retirer" button: minimum touch target height 44px on mobile. Use `py-3` or `min-h-[44px]` on mobile.

## Interaction Contract

> This section is required for this phase due to the gesture-heavy nature of the mobile layer.

### Swipe Day Navigation (source: CONTEXT.md D-01, D-02, D-03)

| Property | Value |
|----------|-------|
| Trigger | touchstart / touchmove / touchend on the day content area |
| Threshold | 30px horizontal displacement (Δx ≥ 30px at touchend) |
| Axis lock | Determined at first movement: if |Δx| > |Δy|, lock to horizontal, call `preventDefault()` to block vertical scroll; else pass through to native scroll |
| Event listener attachment | Imperative `useEffect` with `{ passive: false }` on the container ref — required for `preventDefault` on touchmove |
| Result: swipe left (Δx < 0) | Advance to next day. If current day is Sunday (index 6 of week), increment `weekOffset` and set `selectedDay` to Monday of the new week. |
| Result: swipe right (Δx > 0) | Go to previous day. If current day is Monday (index 0 of week), decrement `weekOffset` and set `selectedDay` to Sunday of the previous week. |
| Below threshold | No day change. |
| Visual feedback during swipe | None — content swaps instantly at touchend (no slide animation, no rubber-band). Source: CONTEXT.md D-01. |

### Mini-Bar Pill Tap (source: CONTEXT.md D-04, D-05, D-06)

| Property | Value |
|----------|-------|
| Tap | `onClick` → set `selectedDay` to the pill's dateStr |
| Week update | If tapped day is outside the current `weekOffset` week, update `weekOffset` to display the correct week |
| Labels | 3-char day abbreviation in `fr-FR` locale ("Lun", "Mar", "Mer", "Jeu", "Ven", "Sam", "Dim"). No date number in pill. |
| Strip update on week boundary | When `selectedDay` crosses a week boundary via swipe, the mini-bar re-renders with the new week's 7 pills automatically (derived from `currentMonday`). |

### Bottom Sheet (source: CONTEXT.md D-07, D-08, D-09)

| Property | Value |
|----------|-------|
| Open trigger | Tap "+" button on any slot |
| Position | `fixed bottom-0 inset-x-0 z-50`, `rounded-t-2xl bg-white shadow-2xl` |
| Max height | `max-h-[80vh] overflow-y-auto` |
| Backdrop | `fixed inset-0 z-40 bg-black/40` |
| Close: backdrop tap | `onClick` on backdrop → close sheet |
| Close: "×" button | Top-right of sheet header → close sheet |
| Close: "Fermer" button | Bottom of sheet → close sheet |
| Close: swipe-down | NOT implemented — conflicts with day swipe navigation. Source: CONTEXT.md D-08. |
| Recipe selection | `RecipeCombobox` (`src/components/RecipeCombobox.tsx`) reused as-is. `onAdd` callback: call `handleAdd(date, mealType, recipeId)`, then close sheet. Source: CONTEXT.md D-09. |
| Slot context | Sheet must receive `{ date, mealType }` to pass correct arguments to `handleAdd`. |
