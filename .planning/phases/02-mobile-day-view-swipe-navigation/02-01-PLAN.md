  Add a single useEffect after the two ref-sync useEffects added in Task 1. This is the touch gesture handler. Rules that MUST be followed exactly:

  The dependency array is empty `[]` — the handler reads state via selectedDayRef.current and weekOffsetRef.current, never from captured state variables.

  Inside the effect: obtain the element from `dayContentRef.current`; return immediately if it is null. Declare three closure-local mutable variables: `startX = 0`, `startY = 0`, `lockAxis` typed as `"h" | "v" | null` initialized to null.

  `onTouchStart(e: TouchEvent)`: records `e.touches[0].clientX` into startX, `e.touches[0].clientY` into startY, resets lockAxis to null.

  `onTouchMove(e: TouchEvent)`: if lockAxis is null and the movement has exceeded 5px in either axis, determine axis lock: set lockAxis to `"h"` if `Math.abs(e.touches[0].clientX - startX) > Math.abs(e.touches[0].clientY - startY)`, else `"v"`. If lockAxis is `"h"`, call `e.preventDefault()` — this call REQUIRES the listener to be attached with `{ passive: false }` otherwise it has no effect.

  `onTouchEnd(e: TouchEvent)`: if lockAxis is not `"h"`, return immediately. Compute `dx = e.changedTouches[0].clientX - startX`. If `Math.abs(dx) < 30`, return (per D-02 threshold). Read `selectedDayRef.current` as `currentDay` and `weekOffsetRef.current` as `currentOffset`. Parse: `const [y, m, d] = currentDay.split("-").map(Number); const date = new Date(y, m - 1, d);`. Compute `dayOfWeek = date.getDay()` (0=Sun…6=Sat), then `weekIndex = dayOfWeek === 0 ? 6 : dayOfWeek - 1` (converts to 0=Mon…6=Sun). Navigation rules:
  - Swipe left (dx < 0) → next day: if weekIndex === 6 AND currentOffset < 4, call `setWeekOffset(currentOffset + 1)` and `setSelectedDay(toDateStr(addDays(getMondayOf(currentDay), 7)))` in the same block (crosses to Monday of next week); else if weekIndex < 6, call `setSelectedDay(toDateStr(addDays(date, 1)))`.
  - Swipe right (dx > 0) → previous day: if weekIndex === 0 AND currentOffset > -4, call `setWeekOffset(currentOffset - 1)` and `setSelectedDay(toDateStr(addDays(getMondayOf(currentDay), -1)))` in the same block (crosses to Sunday of previous week); else if weekIndex > 0, call `setSelectedDay(toDateStr(addDays(date, -1)))`.

  Register listeners: `el.addEventListener("touchstart", onTouchStart, { passive: true })`, `el.addEventListener("touchmove", onTouchMove, { passive: false })`, `el.addEventListener("touchend", onTouchEnd, { passive: true })`. The `{ passive: false }` on touchmove is REQUIRED — omitting it or setting passive to true makes `preventDefault()` a no-op.

  Return a cleanup function that removes all three listeners from `el`.

  DO NOT use React synthetic `onTouchMove` (via JSX prop) — React 17+ delegates synthetic events to the root element and `preventDefault()` does not reliably block scroll from there.
